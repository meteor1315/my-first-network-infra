# Home Network Infrastructure - "Charrin" Project

## About this project
This repository documents the design, physical installation, and administration of my first complete network infrastructure. Deployed in my grandmother's house, the goal of this project is to concretely demonstrate my technical skills, ranging from cable pulling to network configuration. The project is named "Charrin".

## Architecture and Hardware (Phase 1)
The current infrastructure mainly covers the ground floor and is built around the Ubiquiti UniFi ecosystem.

*   **Internet Service Provider (ISP):** Orange (Fiber optic) via a Livebox.
*   **Router / Controller:** Ubiquiti UniFi Cloud Gateway Ultra (UCG-Ultra).
*   **WiFi Access Point:** 1x Ubiquiti UniFi U6+.

## Completed Work (Current State)
*   **Core network setup:** Installation and configuration of the Cloud Gateway Ultra, plugged directly into the Livebox.
*   **WiFi Deployment:** Installation of the U6+ access point to cover the ground floor.
*   **Structured cabling:** Pulling all Ethernet cables through the house to the upper floor to prepare for the future network extension.

## Next steps (Phase 2)
All the cabling for the upper floor is already prepared, but the floor is not yet connected to the active network due to the current budget. 
The next planned interventions at the house are:
*   Installing and crimping the RJ45 keystones on the pending cables.
*   Purchasing and installing a PoE-powered switch to connect the floors.
*   Commissioning and administering this new extension from the console.

# Home Network Infrastructure - Projet "Charrin"

## À propos de ce projet
Ce dépôt documente la conception, l'installation physique et l'administration de ma première infrastructure réseau complète. Déployé dans la maison de ma grand-mère, l'objectif de ce projet est de démontrer de manière concrète mes compétences techniques, allant du tirage de câbles à la configuration réseau. Le projet est nommé "Charrin".

## Architecture et Matériel (Phase 1)
L'infrastructure actuelle couvre principalement le rez-de-chaussée et s'articule autour de l'écosystème Ubiquiti UniFi.

*   **Fournisseur d'accès (FAI/ISP) :** Orange (Fibre optique) via une Livebox.
*   **Routeur / Contrôleur :** Ubiquiti UniFi Cloud Gateway Ultra (UCG-Ultra).
*   **Point d'Accès WiFi :** 1x Ubiquiti UniFi U6+.

## Travaux réalisés (État Actuel)
*   **Mise en place du cœur de réseau :** Installation et configuration du Cloud Gateway Ultra, directement branché à la Livebox.
*   **Déploiement WiFi :** Installation du point d'accès U6+ pour couvrir le rez-de-chaussée.
*   **Câblage structuré :** Tirage de tous les câbles Ethernet à travers la maison jusqu'à l'étage afin de préparer la future extension du réseau.

## Prochaines étapes (Phase 2)
Tout le câblage de l'étage est d'ores et déjà prêt, mais l'étage n'est pas encore relié au réseau actif en raison du budget actuel. 
Les prochaines interventions prévues à la maison sont :
*   L'installation et le sertissage des fiches RJ45 sur les câbles en attente.
*   L'achat et l'installation d'un switch alimenté en PoE pour relier les étages.
*   La mise en service et l'administration de cette nouvelle extension depuis la console.
