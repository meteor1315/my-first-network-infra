# Home Network Infrastructure - Projet "Charrin"

## À propos de ce projet
Ce dépôt documente la conception, l'installation physique et l'administration de ma première infrastructure réseau complète. Déployé dans la maison de ma grand-mère, l'objectif de ce projet est de démontrer de manière concrète mes compétences techniques, allant du tirage de câbles à la configuration réseau. Le projet est nommé "Charrin".

## Architecture et Matériel (Phase 1)
L'infrastructure actuelle couvre principalement le rez-de-chaussée et s'articule autour de l'écosystème Ubiquiti UniFi.

*   **Fournisseur d'accès (FAI/ISP) :** Orange (Fibre optique) via une Livebox.
*   **Routeur / Contrôleur :** Ubiquiti UniFi Cloud Gateway Ultra (UCG-Ultra).
*   **Point d'Accès WiFi :** 1x Ubiquiti UniFi U6+.

## Travaux réalisés (État Actuel)
*   **Mise en place du cœur de réseau :** Installation et configuration du Cloud Gateway Ultra, directement branché à la Livebox.
*   **Déploiement WiFi :** Installation du point d'accès U6+ pour couvrir le rez-de-chaussée.
*   **Câblage structuré :** Tirage de tous les câbles Ethernet à travers la maison jusqu'à l'étage afin de préparer la future extension du réseau.

## Prochaines étapes (Phase 2)
Tout le câblage de l'étage est d'ores et déjà prêt, mais l'étage n'est pas encore relié au réseau actif en raison du budget actuel. 
Les prochaines interventions prévues à la maison sont :
*   L'installation et le sertissage des fiches RJ45 sur les câbles en attente.
*   L'achat et l'installation d'un switch alimenté en PoE (Power over Ethernet) pour relier les étages.
*   La mise en service et l'administration de cette nouvelle extension depuis la console.
