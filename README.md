# my-first-network-infra 

🌐 Home Network Infrastructure - Projet "Charrin"📖 À propos de ce projetCe dépôt documente la conception, l'installation physique et l'administration logique de ma première infrastructure réseau complète. Déployé dans la maison familiale, ce projet a pour but de remplacer un réseau opérateur basique par une solution robuste, évolutive et centralisée, tout en me permettant de consolider mes compétences en ingénierie réseau.🏗️ Architecture Actuelle (Phase 1)Le réseau est actuellement dans sa première phase de déploiement, couvrant principalement le rez-de-chaussée.  Fournisseur d'accès (FAI) : Orange (Fibre optique) via Livebox.Routeur / Contrôleur : Ubiquiti UniFi Cloud Gateway Ultra (UCG-Ultra).  Point d'Accès WiFi : 1x Ubiquiti UniFi U6+.  🛠️ Travaux réalisésInstallation matérielle : Mise en place du Cloud Gateway Ultra et montage du point d'accès U6+.  Câblage structuré : Tirage des câbles Ethernet dans les cloisons jusqu'à l'étage pour anticiper l'extension du réseau.  🚀 Prochaines étapes (Phase 2)L'infrastructure physique de l'étage est prête, en attente de budget pour le matériel actif :Sertissage et installation des prises murales RJ45 et des fiches.  Acquisition et intégration d'un switch PoE (Power over Ethernet) pour alimenter les futurs équipements.Connexion et configuration de l'étage au réseau principal.🧠 Compétences techniques illustréesConception de topologie réseau et simulation de couverture WiFi (2.4 GHz et 5 GHz) via UniFi Design Center.  Câblage physique et intégration dans l'environnement résidentiel.Administration réseau via UniFi OS.
